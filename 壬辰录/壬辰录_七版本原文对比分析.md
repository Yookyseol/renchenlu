## 二、内容异同点

### （一）相同点

1. **核心叙事一致**
   - 均以壬辰倭乱（1592-1598年）为背景
   - 主要人物相同：平秀吉、李舜臣、李如松、加藤清正、小西飞等
   - 主要战役相同：平壤之战、闲山之战、蔚山之战

2. **主题一致**
   - 歌颂抗倭英雄（李舜臣、郭再佑、金德龄等）
   - 谴责倭寇入侵（平秀吉蓄谋、加藤清正凶残）
   - 表彰明朝援军（李如松、陈璘、麻贵等）

3. **诗歌内容基本一致**
   - 多版本均有相同的开篇诗和结尾诗
   - 如"壬辰兵燹遍朝鲜"等诗句在各版本中反复出现

### （二）不同点

#### 1. 开篇方式不同

| 版本 | 开篇方式 | 特点 |
|------|----------|------|
| 东洋文库本 | "壬辰倭乱之际，平秀吉潜蓄逆谋" | 直入主题，简洁明快 |
| 国立中央图书馆本 | "朝鲜东南有日本国" | 从地理叙述入手 |
| 精神文化研究院本 | "话说东南海中有一国，国号日本" | 章回小说体，"话说"起式 |
| 柏克莱本 | "大明崇祯壬辰七月十五日夜，宣祖大王梦中" | 梦境开篇，神异色彩浓 |
| 莫斯科版 | "소설집《임진록》에 대하여" | 学术论文体，含研究前言 |
| 洪吉童传版 | "각설, 이때 조선 대왕께옵서 한 몽사(夢事)를 얻었으니" | 说书人开场，"各说"起式 |
| 手抄本 | "壬辰倭乱之际，平秀吉潜蓄逆谋" | 与东洋文库本相似，但更简略 |

#### 2. 人物称谓差异

|------|------------|------------------|----------|--------|
| 丰臣秀吉 | 平秀吉 | 平秀吉 | 平秀吉 | 平秀吉 |
| 小西行长 | 小西飞 | 平道臣/小西飞 | 鸟西飞 | 小西飞 |
| 加藤清正 | 加藤清正 | 清正/加藤清正 | 加藤清正 | 加藤清正 |
| 金德龄 | 金德龄 | 金德龄 | 金德龄 | 金伊俊（错误） |
| 郭再佑 | 郭再佑 | 郭再佑 | 郭再佑 | 郭再佑 |

#### 3. 叙事详略不同

| 版本 | 特点 |
|------|------|
| 精神文化研究院本 | 最详细，含大量对话、心理描写、战争细节 |
| 东洋文库本 | 较详细，叙事完整，语言优美 |
| 国立中央图书馆本 | 详细，含校点注释 |
| 柏克莱本 | 较简略，但含梦境、神异情节 |
| 莫斯科版 | 韩文谚文，口语化，含大量注释 |
| 洪吉童传版 | 韩文谚文，口语化，叙事简洁 |
| 手抄本 | 最简略，仅保留核心内容 |

#### 4. 文体风格差异

| 版本 | 文体风格 | 语言特点 |
|------|----------|----------|
| 东洋文库本 | 文言小说体 | 文白夹杂，典雅庄重 |
| 国立中央图书馆本 | 文言小说体 | 文白夹杂，有校点 |
| 精神文化研究院本 | 白话小说体 | 接近话本体，"话说"起式 |
| 柏克莱本 | 白话小说体 | 含梦境、神异，传奇色彩 |
| 莫斯科版 | 韩文谚文 | 口语化，通俗生动 |
| 洪吉童传版 | 韩文谚文 | 口语化，说书体 |
| 手抄本 | 简体中文 | 白话文，简洁明了 |

#### 5. 特殊内容差异

| 版本 | 特殊内容 |
|------|----------|
| 柏克莱本 | 含《甲辰录》附录；梦境开篇；关羽托梦情节 |
| 莫斯科版 | 含6篇小说合集（朴婢夫人传、兔传、长髭传、淑香传、裴裨将传）；大量注释 |
| 洪吉童传版 | 含崔一令章节；韩文谚文口语化 |
| 精神文化研究院本 | 有《壬辰录序》；分卷之上/下；篇幅最长 |
| 东洋文库本 | 有"池洁校点"署名；叙事完整 |
| 国立中央图书馆本 | 有"孙逊王乙珈校点"署名；含大量注释 |
| 手抄本 | 无特殊内容，为核心叙事整理本 |

## 三、关键情节对比

### 1. 平壤之战

| 版本 | 叙述特点 |
|------|----------|
| 东洋文库本 | 详细叙述李如松攻城过程，城中火起，倭弃城走 |
| 精神文化研究院本 | 最详细，含李如松登城、矢石交集、身被数创等细节 |
| 柏克莱本 | 含神异色彩，如"云中鸣鼓"、"神兵击之"等 |
| 手抄本 | 简略："如松身先士卒，城中火起，倭乃弃城走" |

### 2. 闲山之战

| 版本 | 叙述特点 |
|------|----------|
| 东洋文库本 | 叙述李舜臣善用车船，倭船不能近 |
| 精神文化研究院本 | 详细叙述李舜臣"八战八捷"，用偶人船、地雷炮等战术 |
| 柏克莱本 | 叙述较简略 |
| 手抄本 | 简略："舜臣善用车船，倭船不能近。每战皆捷" |

### 3. 郭再佑传奇

| 版本 | 叙述特点 |
|------|----------|
| 东洋文库本 | 叙述郭再佑聚义兵，扰倭于庆尚 |
| 精神文化研究院本 | 详细叙述郭再佑"朱衣将军"传奇，倭称"神将" |
| 柏克莱本 | 含梦境、神异色彩，如"云雾蔽天，自空中鸣鼓" |
| 手抄本 | 简略："郭再佑聚义兵，扰倭于庆尚" |

## 四、版本价值评估

| 版本 | 优点 | 缺点 |
|------|------|------|
| 东洋文库本 | 叙事完整，语言典雅，有校点 | 篇幅中等，部分细节略简 |
| 国立中央图书馆本 | 校点精良，注释详细 | 部分段落与东洋文库本重复 |
| 精神文化研究院本 | 篇幅最长，细节最丰富，有序言 | 语言较口语化，部分段落冗长 |
| 柏克莱本 | 含梦境开篇，神异色彩浓，有《甲辰录》附录 | 篇幅较短，部分情节简略 |
| 莫斯科版 | 韩文谚文原文，含注释，有研究论文 | 非汉文原文，需韩语能力 |
| 洪吉童传版 | 韩文谚文口语化，含多篇小说 | 合编本，壬辰录部分相对简略 |
| 手抄本 | 简洁明了，适合快速阅读 | 篇幅最短，细节最少 |

---

## 五、建议

1. **学术研究**：建议使用精神文化研究院本（最详细）+ 东洋文库本（最典雅）对照阅读
2. **情节研究**：建议使用柏克莱本（含梦境、神异情节）
3. **语言研究**：建议使用莫斯科版或洪吉童传版（韩文谚文原文）
4. **快速阅读**：建议使用手抄本（简洁明了）
